## 今天新学的技术点

| 知识点 | 用在哪 |
|---|---|
| `try/except` + `as e` | 单条用例失败不中断整轮评测 |
| `any()` / `all()` | 批量判断"有没有" / "是不是全都有" |
| 列表推导式 | 把"遍历 + 收集"压成一行 |
| 正则 `\{[^}]+\}` | 检查是否含 `{变量}` 形式 |
| JSON 读写（`loads` / `dumps`）| 用例集读取、评测结果落盘 |
| **"赋值是改指向，不是改对象"** | 理解为什么"循环里 append 同一个字典变量"会全部变成最后一条 |
| 变量名 vs 对象 | 为什么打印 `records` 能拿到全部、打印 `checks` 只剩最后一条 |
| `strftime` 到秒 | 避免同分钟跑两次互相覆盖 |
